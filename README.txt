ELECTRO MASTER v2 — PWA для iPhone

Состав архива:
- index.html — интерфейс и логика приложения
- manifest.json — параметры установки PWA
- sw.js — офлайн-кеш приложения
- icon-192.png / icon-512.png — иконки

ВАЖНО ПЕРЕД ОБНОВЛЕНИЕМ С v1:
1. На текущем ELECTRO MASTER v1 открой «Ещё» → «Экспорт базы».
2. Сохрани JSON-файл резервной копии в приложение «Файлы» на iPhone.
3. Не удаляй старое приложение и не очищай данные Safari.
4. Только после этого замени файлы в корне существующего GitHub-репозитория и дождись публикации GitHub Pages.
5. Закрой ELECTRO MASTER полностью и открой снова. Проверь историю смет, материалы, работы и клиентов.
6. Если данные не отображаются, используй «Ещё» → «Импорт базы» и выбери JSON-файл, созданный на шаге 1.

МИГРАЦИЯ ДАННЫХ:
- Используется прежний ключ localStorage: electro_master_db_v1.
- При чтении базы v1 сохранённые сметы нормализуются: старые поля total, materialTotal, laborTotal и price преобразуются в поля v2 с суффиксом MDL.
- Импорт резервной копии v1 также проходит через ту же миграцию.
- Старые суммы v1 хранились в MDL; EUR применялся как валюта отображения по курсу.
- Каталожные цены и денежные суммы внутри приложения хранятся в MDL. EUR — отображение по редактируемому курсу.

ВОЗМОЖНОСТИ ЭТОЙ СБОРКИ:
- Локальная база материалов и работ с редактируемыми ценами.
- Сметы с количеством, ценами, дополнительными расходами и итогами.
- Клиенты и история сохранённых смет.
- Ручной учёт складских остатков и расходов.
- Экспорт и импорт резервной копии JSON.
- Печать сметы через системную печать / сохранение PDF.
- Офлайн-кеш оболочки приложения после первого успешного открытия.

ОГРАНИЧЕНИЯ:
- Это PWA-прототип, а не нативное iOS-приложение.
- Полноценный журнал складских движений ещё не реализован.
- Расходы вводятся вручную; чистая прибыль и бухгалтерский учёт автоматически не рассчитываются.
- PDF формируется средствами системной печати.
- Данные находятся в локальном хранилище браузера устройства. Очистка данных Safari может удалить их. Регулярно сохраняй резервные копии.

Перед любым обновлением обязательно экспортируй резервную копию.
