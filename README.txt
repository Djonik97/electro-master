ELECTRO MASTER — стартовый проект v1.0

Состав:
- index.html — интерфейс и логика приложения
- manifest.json — параметры установки PWA
- sw.js — кеширование для офлайн-режима
- icon-192.png / icon-512.png — значки приложения

ВАЖНО:
1. Для установки PWA на iPhone проект нужно разместить на HTTPS-хостинге.
2. Открой опубликованный HTTPS-адрес в Safari → Поделиться → На экран «Домой».
3. Данные хранятся в localStorage браузера на этом устройстве. Не очищай данные Safari без резервной копии.
4. PDF: в редакторе сметы нажми «Печать / сохранить PDF», затем используй диалог iOS для сохранения в Файлы.

Это стартовый MVP, не окончательная бухгалтерская система. Курс EUR/MDL пока сохраняется в настройках, автоматическая конвертация и расширенная финансовая модель будут добавлены следующим этапом.
